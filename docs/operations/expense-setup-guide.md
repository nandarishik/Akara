# Expense tracking setup (Phase 8)

Food cost % and labour cost % need expense rows in Akara.

## What to upload

1. Go to **Data** → upload café expenses (CSV/XLSX) or connect a live ledger later.
2. Map columns to expense category, amount, and date.
3. Confirm mapping and wait for import to complete.

## Categories that feed food cost

- Food / COGS / raw materials
- Packaging (if you track it separately)

## Categories that feed labour cost

- Salaries, wages, contractor kitchen staff

Until expenses exist, dashboard food cost shows **—** with a setup CTA (not zero).

See also: café import wizard on `/data/upload`.
